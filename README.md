Run locally
Clone the repository:
bash
git clone https://github.com/tenalihansika-prog/tenalihansikaportfolio.git
cd tenalihansikaportfolio
Open index.html in your browser, or use the Live Server extension in VS Code (right-click index.html → Open with Live Server).
Deploy on GitHub Pages
Go to Settings → Pages in this repository.
Under Branch, select main and folder / (root), then click Save.
The site goes live at https://tenalihansika-prog.github.io/tenalihansikaportfolio/.
